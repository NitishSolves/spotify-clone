# Spotify Clone

A responsive Spotify web player UI built with **HTML & CSS only** (vanilla, no frameworks).

> ⚠️ **Best viewed on Desktop** — This project is optimized for desktop/laptop screens (1024px+).

## 🎵 Features

- Clean, dark theme matching Spotify's design
- Responsive layout with sidebar navigation
- Music player bar with playback controls
- Trending and featured playlist cards
- Progress bar with play/pause/skip controls
- Volume slider
